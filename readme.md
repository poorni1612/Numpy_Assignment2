🧑‍💻 JavaScript Assignment – Smart Billing System 

📌 Problem Statement 

You are asked to create a Smart Billing System for a small store using JavaScript. 

📝 Requirements 

Collect data using variables: 

Customer name 

Customer type (Regular or Premium) 

Total purchase amount 

Display a menu: 

 

Choose an action: 
1. Calculate Discount 
2. Add GST 
3. Final Bill Amount 
4. Payment Method Message 
 

Use a switch case to handle the user’s Payment Method menu choice. 

🔹 Option 1: Calculate Discount 

Apply discount based on customer type: 

Premium customer 

Purchase ≥ ₹5000 → 20% discount 

Purchase < ₹5000 → 10% discount 

Regular customer 

Purchase ≥ ₹5000 → 10% discount 

Purchase < ₹5000 → 5% discount 

Use: 

Arithmetic operators 

Comparison operators 

if-else conditions 

🔹 Option 2: Add GST 

Add 18% GST to the purchase amount 

Display GST amount and total amount 

Use: 

Arithmetic operators 

🔹 Option 3: Final Bill Amount 

Final Bill = Purchase Amount – Discount + GST 

Display final payable amount 

Use: 

Arithmetic operators 

🔹 Option 4: Payment Method Message 

Ask the user to choose a payment method: 

1 → Cash 

2 → UPI 

3 → Card 

Display a message based on the choice using switch case.
